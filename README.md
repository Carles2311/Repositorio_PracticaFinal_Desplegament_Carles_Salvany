# Práctica DevOps 2026 — Despliegue Automatizado de CV Online

## 📝 Descripción
Este proyecto consiste en la implementación y automatización de un pipeline de Integración Continua y Despliegue Continuo (CI/CD) para un Currículum Vitae (CV) online interactivo. La arquitectura consta de una interfaz web y un backend desarrollado en PHP. El objetivo principal de la práctica es eliminar los despliegues manuales mediante SSH o copias de archivos a mano, permitiendo que cualquier cambio subido al repositorio se valide y compile de forma 100% automatizada a través de un ecosistema moderno de herramientas DevOps.

## 🛠️ Tecnologías
* **Backend / Scripting:** PHP (Validación de sintaxis nativa)
* **Orquestación CI/CD:** Jenkins (Servidor en contenedor Docker) & GitHub Actions
* **Contenedores:** Docker & Docker Compose (Virtualización de Jenkins)
* **Seguridad y Redes:** ngrok (Túnel seguro para la recepción de Webhooks) o Poll SCM
* **Optimización y CDN:** Cloudflare (Cifrado Full Strict HTTPS, Proxy Inverso y mitigación DDoS)
* **Gestión de Medios:** ImageKit.io (Optimización automática de imágenes y compresión en formato WebP en tiempo real)
* **Control de Versiones:** Git & GitHub

## ⚙️ Instalación

### Requisitos Previos
* Tener instalado **Docker Desktop** en Windows con el backend de WSL2 activo.
* Tener instalado **Git** y **PHP** (o un entorno integrado como XAMPP) en las variables de entorno de Windows.
